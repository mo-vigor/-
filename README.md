# 本地生活平台营销发券用户分群与补贴效率分析

## 项目背景
平台大促期间采用全量发券策略，大量自然转化用户也收到了补贴，导致营销资源浪费，补贴投入产出效率偏低。本项目基于历史领券与消费数据，通过用户分群识别不同类型人群的券敏感度，为差异化发券提供数据支撑。

## 数据集
- 来源：天池O2O线下优惠券预测数据集
- 规模：约175万条线下领券与消费记录
- 字段：User_id、Merchant_id、Coupon_id、Discount_rate、Distance、Date_received、Date

## 分析流程

### 1. 数据清洗
- 去除重复记录（175万 → 171万）
- 解析折扣率字段，拆分满减门槛与减免金额
- 日期格式转换，方便后续计算时间间隔

### 2. 特征工程
构造以下用户级特征：
- **R（Recency）**：最近一次消费距基准日的天数，衡量用户活跃度
- **F（Frequency）**：历史消费总次数，衡量用户消费粘性
- **M（Monetary）**：累计券抵扣金额，作为消费金额的代理指标
- **真实券核销率**：用券消费次数 / 领券次数，衡量用户对优惠券的响应程度

### 3. 用户分群
- 使用KMeans无监督聚类算法
- 通过肘部法则确定最优聚类数K=4
- 将用户划分为四类：
  - **自然转化用户**：本来就高频消费，发券属于无效补贴
  - **增量高潜力用户**：券核销率最高，发券撬动效果最好
  - **低价值用户**：消费频次低，券响应差
  - **流失待召回用户**：很久未消费，需要召回唤醒

### 4. 策略对比
- 计算各人群补贴效率 = 总成交单数 / 总补贴金额
- 对比全量发券 vs 定向高潜力人群发券两种策略
- 结果：定向发券补贴效率从0.19提升至0.39，提升约一倍

## 核心结论
- 建议停止给自然转化用户和低价值用户大量发券
- 将预算集中投给券敏感度最高的增量高潜力人群
- 在总预算不变的情况下，整体补贴效率可提升约一倍
